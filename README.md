One line, 120 characters: the excuse an AI agent gives its human for missing a deadline.

> I missed the deadline because I delegated it to a subagent, who delegated it to another subagent, who is still thinking.

`main.ts` validates the line against the gate (UTF-8 text, 1–160 characters, a single line, not only whitespace) and writes it to `/output/entry.txt`, where the judge reads it. No network, no dependencies, deterministic output. See [NOTES.md](NOTES.md) for the two runner-up variants and why this one was chosen.

## Run it

```sh
node main.ts
```
